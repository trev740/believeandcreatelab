Installation

Windows

Option 1: Setup method (.exe)

  1. Download and open the .exe installer.
  2. Follow the on-screen installation instructions.

Option 2: Manual method (.zip)

  1. Download and unzip the plugin archive.
  2. Copy the data and obs-plugins folders to: C:\Program Files\obs-studio

macOS

Option 1: Setup method (.pkg)

  1. Download and open the .pkg installer.
  2. Follow the on-screen installation instructions.

Option 2: Manual method (.zip)

  1. Download and unzip the plugin archive.
  2. Copy streamlens-obs.plugin to: ~/Library/Application Support/obs-studio/plugins

After installation

  1. Restart OBS Studio.
  2. Add StreamLens Device as a source.
  3. Open StreamLens on your iPhone while both devices are connected to the same Wi-Fi network.
